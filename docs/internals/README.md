# Documentos internos de V3

Notas, análisis y material de trabajo generados durante el desarrollo de
V3. **No es material canónico para la revisión pública de la tesis**: la
narrativa oficial está en la tesis, los papers y los repositorios
hermanos. Estos archivos se conservan aquí para auditoría y referencia
histórica.

## Qué hay aquí

| Archivo                              | Origen              | Descripción                                                                                |
| ------------------------------------ | ------------------- | ------------------------------------------------------------------------------------------ |
| `ANALISIS_V3.md`                     | Análisis técnico    | Recorrido por la implementación Java V3, `OptimizedSubnetDivider`, `ForkJoinPool`, etc.   |
| `GENERADOR_S3PR_OPTIMIZADO.md`       | Generador S3PR      | Notas sobre el generador escalable de redes S3PR usado en las campañas comparativas.       |

## Política de mantenimiento

Estos archivos se preservan tal como estaban al cierre del ciclo de
trabajo de V3. V3 sigue siendo útil como generador S3PR y como referencia
de la división automática balanceada. La versión final algorítmica es V4
(`juanchula/reachability-tree-algo`).
